### About Me

- I started my coding journey as a student at SMA Trinitas Bandung.
- I enjoy building clean front-end experiences and learning how good design supports good code.
- My current learning path is focused on HTML, CSS, JavaScript, React, Node.js, and Python.
- I like projects that feel calm, useful, and intentional rather than noisy.
- Outside coding, I play Valorant, explore ideas, and keep chasing steady progress.
- Long-term goal: become a Software Engineer and build things that matter.
